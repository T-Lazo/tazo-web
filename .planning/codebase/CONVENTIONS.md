# Conventions

## Naming
- **Components**: PascalCase (e.g., `TabbedInterface.tsx`).
- **Files**: PascalCase for components, camelCase for utilities (if any).
- **Directories**: lowercase/kebab-case for generic folders (`components`, `app`).

## Code Style
- **Imports**: Absolute imports using `@/` alias.
- **Styling**: Tailwind CSS utility classes.
- **React**: Functional components with Hooks.
- **Directives**: `"use client"` for interactive components.

## Typing
- **TypeScript**: Strict mode enabled.
- **Props**: Explicit interfaces/types for component props.
